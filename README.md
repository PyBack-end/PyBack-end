# Hi, I'm Njabulo Thango

**Njabulo / PyBack-end**

I'm a self-taught software developer from South Africa and an aspiring **Software Engineer / Full-Stack Developer**, with a strong focus on **backend engineering, system architecture, AI/ML, distributed systems, and scalable infrastructure**.

I started seriously learning software development at **15**.

What started with learning how to build websites and small applications gradually became an interest in understanding how complete software systems work — from databases and APIs to authentication, infrastructure, AI systems, and distributed architecture.

Today, I focus less on simply making an application work and more on understanding **why the architecture works**.

# How I Build Software

I prefer an **architecture-first approach**.

```text
Problem
   ↓
Requirements
   ↓
Architecture
   ↓
Data Model
   ↓
Authentication
   ↓
API
   ↓
Business Logic
   ↓
Testing
   ↓
Frontend
   ↓
Infrastructure
   ↓
Deployment
   ↓
Monitoring
```

I believe in:

- Designing before coding
- Building MVPs
- Testing systems
- Refactoring when necessary
- Understanding trade-offs
- Keeping architecture proportional to the problem
- Learning from failed implementations
- Building for real users

I don't want to over-engineer everything.

The goal is to build the **simplest architecture that correctly solves the problem**, then evolve it as requirements grow.
